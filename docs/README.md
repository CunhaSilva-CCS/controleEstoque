## Regra de manutenção

- Atualize o Manual do Utilizador quando a interface ou o fluxo operacional mudar.
- Atualize a Especificação Funcional quando uma regra de negócio mudar.
- Registe procedimentos técnicos apenas no Guia de Operação; não os duplique no manual do cliente.
- Relatórios com data ou versão são evidências históricas e não substituem os guias permanentes.
